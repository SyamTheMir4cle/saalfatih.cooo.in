# Personal Portfolio Website - Next.js Edition

This repository contains the source code for my personal portfolio website, now rebuilt with Next.js. This migration was done to leverage a modern, component-based architecture, improve performance with Server-Side Rendering, and create a more scalable and maintainable codebase.

**Live Demo:** [https://saalfatih.cooo.in](https://saalfatih.cooo.in)

-----

### ✨ Features

  * **Responsive Design:** Looks great on desktops, tablets, and mobile phones.
  * **Component-Based Architecture:** Fully modular and reusable UI components built with React.
  * **Rich Animations:** Smooth and interactive animations powered by the GSAP library.
  * **Project Showcase:** A dedicated section to display my best work with links.

-----

### 💻 Tech Stack

This project was rebuilt using a modern front-end stack:

  * **Framework:** [Next.js](https://nextjs.org/)
  * **Library:** [React](https://reactjs.org/)
  * **Styling:** CSS Modules / Global CSS
  * **Animations:** [GSAP (GreenSock Animation Platform)](https://www.google.com/search?q=https://greensock.com/gsap/)

-----

### 🚀 Getting Started

To run this project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/SyamTheMir4cle/saalfatih.cooo.in.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd saalfatih.cooo.in
    ```
3.  Install the necessary dependencies:
    ```bash
    npm install
    ```
4.  Run the development server:
    ```bash
    npm run dev
    ```
5.  Open [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) in your browser to see the result.
